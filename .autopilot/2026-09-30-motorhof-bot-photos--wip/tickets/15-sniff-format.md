## Что должно заработать

В бою MH_1016: все 25 «DNG» дали «файл повреждён или не читается». Образец `IMG_3729.DNG` — на деле JPEG
(MPO, 4032×3024, 3,5 МБ, iPhone 13 Pro Max, iOS 18.3.2): телефон при загрузке в Drive отдал совместимый
формат под исходным именем. rawpy: `LibRawFileUnsupportedError`. Фикстура лежит в `tests/fixtures/IMG_3729_jpeg_named.DNG` (не в git — .gitignore по *.DNG).

## Критерии приёмки

- [ ] Декодер выбирается по сигнатуре содержимого: JPEG (`FF D8 FF`), HEIC/HEIF (ISO-BMFF `ftyp` heic/heix/mif1/msf1…), TIFF/DNG (`II*\0`/`MM\0*`); расширение — только фильтр «что вообще берём» (как сейчас).
- [ ] `.DNG` с JPEG внутри → конвертируется как JPEG (ориентация, ICC→sRGB, EXIF по белому списку без GPS, ресайз); с HEIC внутри — как HEIC. Настоящий DNG — как сейчас (вшитый JPEG / rawpy).
- [ ] Неизвестная сигнатура или битый файл → по-прежнему `ConvertError(UNREADABLE)`.
- [ ] Отпечаток params: для `.DNG`-файла, оказавшегося JPEG/HEIC, — без DNG_METHOD (или с отдельной меткой) — на твоё усмотрение, но так, чтобы повторный прогон не пересчитывал заново уже сделанное.
- [ ] Тесты: фикстура (skipif без файла) → JPEG 2000 px, яркость разумная (>60), GPS пуст; синтетика: JPEG и HEIC, сохранённые с расширением .DNG/.jpg/.heic в любых сочетаниях; мусор с .DNG → UNREADABLE.
- [ ] Полный прогон зелёный.
