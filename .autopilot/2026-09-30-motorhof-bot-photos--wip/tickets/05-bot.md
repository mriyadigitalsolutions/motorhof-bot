## Что должно заработать

`python -m bot.main` поднимает aiogram (long polling), подключает модули из реестра, запускает
воркер очереди. Чужие ID и группы — полное молчание + строка в лог. `/fotos MH_1022 [full]`:
нормализация номера, подсказки на неверный ввод, постановка в очередь, три сообщения
(очередь → «N файлов, конвертирую» → итог со ссылкой). Любое падение → сообщение партнёру и
`failed` в журнале. При старте — уведомление владельцам прерванных задач. `/status`, `/last`,
`/start`, `/help`. Журнал `runs` пишется на каждый запуск. Админы вычисляются (для таска 06).

## Из брифа, дословно

> «партнёр пишет боту `/fotos MH_1022` (или `/fotos KO_2001`)»
> «Доступ только у трёх партнёров по Telegram-ID из .env; остальным бот не отвечает.»
> «Бот отвечает на каждую ошибку понятным сообщением на русском и никогда не молчит при падении задачи.»
> «команды `/status` и `/last` показывают, что происходит и что было»

## Критерии приёмки

- [ ] `parse_car_code` принимает `MH_1022`, `mh1022`, `MH1022`, `KO 2001`, `ko_2001`; отвергает `1022`, пустое, `XX_12` — с текстами из спецификации; неизвестный вариант → список доступных
- [ ] `AccessMiddleware`: чужой ID, группа → хендлер не вызывается, ответа нет, лог с ID и командой без текста; админ вне списка партнёров — не партнёр и не админ (лог-предупреждение)
- [ ] Постановка: «в очереди, позиция N»; дубль → «уже в очереди, позиция N» / «уже обрабатывается»; переполнение → текст из спецификации
- [ ] Не больше трёх сообщений на задачу; исключение в job → «задача упала: …»; `runs` заполнен (`user_name` из Telegram)
- [ ] Старт с зависшей `running` → уведомление «прервана перезапуском…», очередь продолжается
- [ ] `/status` с прогрессом «(12/24)», `/last` 10 строк моноширинно, пустой журнал → «Запусков ещё не было»; `/help` и `/start`
- [ ] Тесты без сети Telegram (сервисные функции + фейковый бот/`send`)
