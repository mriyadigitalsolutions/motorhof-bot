# 08 — Доводка по отложенным находкам ревью

**Требования:** R26, R25, R33, R45, R24 (разбор отложенных находок, Phase 8 §1a)
**Blocked by:** 01–07
**Зона:** `core/settings.py` `core/queue.py` · `modules/photos/handlers.py` `modules/photos/reminders.py` `modules/photos/job.py` `modules/photos/__main__.py` `modules/photos/convert.py` · `tests/` (все conftest и тесты, которые затрагивают пункты ниже)
**Волна:** 6
**Status:** ready

## Что должно заработать

Ничего нового для пользователя — закрываются находки ревью, которые повторились в трёх и более тасках
или являются настоящими ошибками поведения.

## Критерии приёмки

- [ ] `core.settings`: значение со знаком `#` внутри (путь, имя папки) не обрезается; комментарий отрезается только если перед `#` пробел и значение не в кавычках. Тест подаёт сырые строки вида `10   # комментарий` и `/data/a#b`.
- [ ] `core.queue`: публичный способ подключить notify без запуска воркера (например `set_notify(fn)`), и публичный способ для обработчика завершить задачу статусом failed **без** общего текста «задача упала» (например исключение `JobFailedQuietly` / `SilentFailure`). `photos.delete_dng` переходит на него; адресаты у задачи удаления снова могут быть (chat_id партнёра), тест: сбой удаления → failed, «задача упала» никому не ушло.
- [ ] Тесты больше не трогают внутренности очереди: `q._claim`, присваивание `queue.notify` (tests/core, tests/bot, tests/photos_reminders) — только публичные методы.
- [ ] Тест «одна задача за раз» может покраснеть: запущенный воркер (`start`), два обработчика, которые могли бы пересечься, проверка, что пересечения не было.
- [ ] Общие тестовые помощники — одна реализация: `vienna_tz`, синтетический JPEG, дерево «как на Drive» — в `tests/conftest.py` или `tests/fakes/`; копии удалены.
- [ ] `photos.handlers`: `ensure_schema` один раз при регистрации; строка `photos_job_runs` удаляется при завершении/прерывании задачи.
- [ ] `job`: причина `ManifestCorrupt` пишется в лог (warning), партнёру — прежний текст.
- [ ] `__main__`: код 2 только для неверных аргументов/неизвестного варианта; прочие ошибки не маскируются под него.
- [ ] `convert`: один список поддерживаемых расширений (`.heif` либо в обоих местах, либо ни в одном).
- [ ] Полный прогон зелёный, число тестов не меньше 243.
