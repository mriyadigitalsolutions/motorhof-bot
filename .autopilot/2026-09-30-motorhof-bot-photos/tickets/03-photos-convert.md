## Что должно заработать

Из папки с DNG/HEIC/JPG получается папка с `MH_1022_01.jpg…` (listing) и, по запросу,
`MH_1022_01_full.jpg`, плюс `_manifest.json`. Без Drive и без бота:
`python -m modules.photos --in <папка> --out <папка> --mh MH_1022 [--variant full]`.
Повторный запуск ничего не пересчитывает; дозаснятые получают следующие номера; смена
параметров в yaml пересчитывает под теми же именами; битый файл пропускается с именем в отчёте.
В выходе: sRGB с вшитым профилем, Orientation=1, EXIF по белому списку, без GPS и MakerNote.

## Из брифа, дословно

> «берёт все исходники из подпапки `Фотографии` (DNG с iPhone ProRAW, HEIC, JPG), конвертирует их в JPEG»
> «с именами `MH_1022_01.jpg`, `MH_1022_02.jpg` и так далее»
> «Порядок по дате съёмки из EXIF. GPS из EXIF удаляется.»
> «Повторный запуск не пересчитывает уже сделанные файлы и не создаёт дубликатов (манифест с хэшами).»
> «Размеры и качество на выходе задаются в конфиге, а не в коде; первый вариант: длинная сторона 2000 px, качество 92.»
> Дополнения: ProRAW — «в»; варианты — listing + full; нумерация — «а» (готовые имена не меняются)

## Критерии приёмки

- [ ] `variants.yaml`: `listing` (2000, 92, subsampling 0, suffix "") и `full` (без ресайза `max_side: null`, 95, suffix `_full`, `on_demand: true`)
- [ ] DNG-фикстура → JPEG 2000 px по длинной стороне, rawpy с параметрами PLAN §4; HEIC-фикстура → sRGB-профиль, GPS-IFD пуст, DateTimeOriginal сохранён; синтетика с Orientation=6 → портрет; JPG < 2000 px не увеличивается
- [ ] Порядок: DateTimeOriginal → mtime → имя; нумерация `NN` (≥100 → три цифры)
- [ ] Идемпотентность: второй прогон — 0 рендеров; добавленный ранний снимок → следующий номер; удалённый исходник → `orphan: true`; заменённый (то же имя, другой хэш) → новый номер + orphan; удалённый выход → пересоздан; изменённый `quality` → пересчёт под тем же именем; `src_deleted: true` не делает orphan
- [ ] Битый файл (0 байт, обрезанный) → пропуск, имя и причина в отчёте, остальные сделаны
- [ ] Запись через `.part` + rename; тесты на реальных фикстурах `skipif` при их отсутствии
