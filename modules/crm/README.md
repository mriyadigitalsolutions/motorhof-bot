# Модуль crm

Задел под следующую версию. Сейчас — только кнопка «CRM» в главном меню; она неактивна (`modules.MENU["crm"]["enabled"] = False`) и отвечает всплывающим «В разработке».

Контракт обмена с CRM (номер машины от CRM, `POST /api/bot/v1/vehicles`, `driveFolderId`) — ТЗ v1.0, раздел 10. Код клиента появится в фазе F; номер машины модули уже берут через `core/numbering.NumberSource`, поэтому замена `ManualNumberSource` на источник из CRM модули не меняет.
