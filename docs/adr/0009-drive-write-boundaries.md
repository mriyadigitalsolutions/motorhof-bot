## Контекст

До фазы B бот писал на Drive только JPEG в `<машина>/Фотографии/На выгрузку/`, переименовывал файлы там же и отправлял в корзину DNG прямо в `<машина>/Фотографии/` (ADR 0005). Фаза B ТЗ (3.2) добавляет «Создать папку машины»: бот сам создаёт `<PREFIX>_AUTO_НАЛИЧИЕ/<год>/<PREFIX>_<номер>_<Марка>_<Модель>/` с подпапками `Фотографии`, `Документы`, `Verkauf`. ТЗ 3.5: модуль никогда не удаляет файлы; единственные операции — создать папку, переместить папку, записать файлы в `Фотографии`, записать JPEG в `На выгрузку`; `Документы` и `Verkauf` бот только создаёт — не читает, не принимает в них файлы и не показывает их содержимое (до заключения Datenschutzberater; по `Verkauf` — навсегда: там данные покупателя). Общий диск — живые документы OG, ошибка в пути бьёт по чужим данным.

## Решение

Все границы — в `core/drive.py`, проверка до вызова rclone, нарушение — `PermissionError` (rclone не зовётся):

| Операция | Что разрешено | Метод |
| --- | --- | --- |
| запись файла, mkdir | только внутри `<машина>/<SOURCE_SUBDIR>/<OUTPUT_SUBDIR>/` | `push`, `push_many`, `mkdir` |
| переименование | файл прямо в `На выгрузку` → другое имя там же | `rename` |
| удаление | только `*.dng` прямо в `<машина>/<SOURCE_SUBDIR>/`, в корзину | `delete_to_trash` |
| создание новой машины | `<MH\|KO>_AUTO_НАЛИЧИЕ/<4 цифры>`, в ней `<тот же префикс>_<цифры>_<Марка>_<Модель>` (латиница, цифры, `-`, `_`; до 100 символов), в ней только подпапки `SOURCE_SUBDIR`, `SUBDIR_DOCS`, `SUBDIR_SALES` | `mkdir_vehicle` |

`mkdir_vehicle(prefix, year, name, subdirs) -> list[str]` — единственная дверь для новой машины. Сначала проверяет все пути, потом ходит в Drive: нет корня НАЛИЧИЕ — ошибка (корни бот не создаёт); папки года нет — создаёт; папка машины уже есть — `FileExistsError`, ничего не создаётся; затем папка машины и подпапки по одной. Возвращает созданные пути по порядку. Сбой rclone на любом шаге — `VehicleMkdirError` (подкласс `DriveError`) с полем `created`: что этот вызов уже успел создать; после сбоя дальше не идёт. Модуль пишет `created` в журнал (`vehicle.folder_created`, status `failed`) и называет партнёру.

Общий `mkdir` своей границы не расширяет: папку `<машина>/Verkauf` через него по-прежнему создать нельзя.

`Документы` и `Verkauf` бот не листает: `mkdir_vehicle` листает только корень (есть ли НАЛИЧИЕ) и папку года (есть ли папка машины); поиск номера (`find_car`) — листинг корней глубины 2, внутрь машин не заходит. Ссылки после создания — `find_dir` папки машины и `Фотографии`, то есть листинг папки года и папки машины (имена подпапок, без содержимого).

## Почему

- Отдельный метод на всю структуру, а не расширение `mkdir`: граница описывает целую операцию «новая машина», а не любой путь, который случайно совпал с шаблоном. Узкий `mkdir` остаётся для `На выгрузку`; тест на запрет `mkdir(<машина>/Verkauf)` остаётся в силе.
- Только НАЛИЧИЕ: новая машина не может родиться проданной; ПРОДАНО появится только переносом (фаза «Перенести в продано», отдельная граница).
- Префикс имени совпадает с префиксом корня: `KO_…` в `MH_AUTO_НАЛИЧИЕ` сломал бы поиск по номеру и нумерацию.
- Корни не создаются: опечатка в `DRIVE_ROOT` не должна плодить пустые деревья на общем диске.
- `FileExistsError` при существующей папке: rclone `mkdir` молча проходит по существующей, и бот иначе «создал» бы подпапки в чужой машине. Модуль ещё раньше ищет номер во всех четырёх корнях — это вторая линия.
- `created` в исключении, а не откат: ТЗ запрещает боту удалять, поэтому частично созданное остаётся, а партнёр получает точный список и разбирается в Drive руками; повтор с тем же номером упрётся в проверку номера.
- Имена подпапок из настроек (`SUBDIR_DOCS`, `SUBDIR_SALES`, `SOURCE_SUBDIR`): переход на схему CRM (`Dokumente / Online / Verkauf`, ТЗ 6) — правка `.env`, не кода.

## Последствия

- Новая операция записи на Drive = новая строка в таблице выше, своя проверка в `core/drive.py` и тест «вне границ → PermissionError, rclone не вызван».
- Переименование `SUBDIR_*` в `.env` после того, как папки созданы, не переименует старые: граница пустит создавать только новые имена.
- Перенос в ПРОДАНО (ТЗ 3.3) потребует своей границы на `moveto` папки целиком — это решение ещё впереди.
