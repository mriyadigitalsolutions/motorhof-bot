## Контекст

Бриф: имена `MH_1022_01.jpg…`, порядок по дате съёмки из EXIF, повторный запуск не создаёт дубликатов. Противоречие: дозаснятое позже фото с более ранней датой по правилу «по дате» должно встать в начало и сдвинуть все номера. Выбор задан заказчику.

## Решение

Решение заказчика — вариант «а»: готовые имена не меняются никогда; дозаснятые фото получают следующие свободные номера, внутри одного запуска новые упорядочены по дате. Реализуется через `_manifest.json` в `На выгрузку`: ключ — SHA-256 исходника, один SHA-256 — один номер `nn` для всех вариантов, новый — `max(nn) + 1`; хранится отпечаток параметров варианта (смена параметров — пересчёт под теми же именами); удалённый исходник помечается `orphan`, его JPEG остаётся; манифест заливается последним; битый или чужой манифест — остановка без записи.

## Почему

- Перенумеровывать всё по дате на каждом запуске (вариант, который заказчик не выбрал): имена уже выложенных на willhaben / AutoScout24 файлов менялись бы, и ссылки/порядок в объявлениях расходились бы с папкой.
- Команда `/fotos … заново` для полной перенумерации была предложена вместе с «а»; заказчик ответил «а» и на явное «команду не делаю — скажи, если нужна» не возразил. Не строится.
- Ключ по имени исходника: замена файла тем же именем не распозналась бы (история 27).
- Разные номера для `listing` и `full`: связь «тот же номер — тот же исходник» (история 16) потерялась бы.
- Пересоздавать при битом манифесте с нуля: затёрло бы уже выданные имена — именно то, что заказчик запретил.

## Последствия

- После дозаснятия нумерация перестаёт совпадать с хронологией: снимок, сделанный раньше всех, может оказаться `_25`.
- Номера осиротевших файлов не освобождаются, дырки не закрываются; осиротевшие JPEG копятся в `На выгрузку`, пока их не удалят руками.
- Манифест — единственный источник правды о номерах. Ручная правка или порча требуют ручного вмешательства: бот в этом случае просто останавливается.
- Перенумеровать машину штатно нельзя; нужна будет отдельная задача по слову заказчика.
- Смена параметров варианта в yaml пересчитывает все файлы этого варианта у каждой машины при следующем запуске.
